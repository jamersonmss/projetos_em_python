# 🧮 Calculadora MEI de Serviços

Uma aplicação desktop desenvolvida em **Python** utilizando **Tkinter**, criada como projeto de estudo para praticar lógica de programação, interfaces gráficas e tratamento de dados informados pelo usuário.

> 📚 **Projeto para estudo de caso:** esta aplicação foi desenvolvida exclusivamente para fins educacionais e de aprendizado em Python. Os cálculos apresentados são simulações e não devem ser considerados orientação contábil, tributária ou fiscal.

---

## 📌 Sobre o projeto

A **Calculadora MEI de Serviços** permite informar valores financeiros relacionados à atividade de um Microempreendedor Individual prestador de serviços e visualizar uma estimativa baseada nas regras implementadas no código.

O projeto foi criado durante meus estudos de Python, com foco em:

- 🐍 Fundamentos de Python
- 🖥️ Desenvolvimento de interfaces gráficas com Tkinter
- 🧮 Operações e lógica de cálculo
- 💰 Tratamento de valores monetários
- ✅ Validação de entradas do usuário
- ⚠️ Tratamento de erros
- 🎨 Organização de uma interface gráfica
- 📦 Uso de ambientes virtuais (`venv`)
- 🌳 Versionamento com Git e GitHub

---

## ✨ Funcionalidades

A aplicação possui campos para informar:

- 💵 Receita Bruta
- 🧾 Despesas da Empresa
- 👥 Dependentes
- 🎓 Educação
- 🏥 Saúde
- 📋 Outros valores

A interface também oferece:

- ✅ Validação dos valores informados
- 🇧🇷 Suporte a valores no formato brasileiro
- 💰 Formatação dos resultados em reais
- 🔴 Destaque para campos com valores inválidos
- 🧹 Botão para limpar o formulário
- ⌨️ Atalho `Enter` para calcular
- ⌨️ Atalho `Esc` para limpar
- 📊 Exibição organizada dos resultados

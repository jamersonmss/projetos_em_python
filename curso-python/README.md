# Curso de Python 3: do básico ao avançado

Este diretório reúne minhas anotações, exercícios e projetos desenvolvidos ao longo do curso **Python 3 do básico ao avançado — com projetos reais**. Vou atualizar o conteúdo conforme avanço pelas aulas.

## Aulas e atividades

| Arquivo | Conteúdo |
|---|---|
| [aula1.py](aula1.py) | Primeiros comandos de saída no terminal com `print()` e prática de execução no Code Runner. |

## Executar os exemplos

Com Python 3 instalado, execute os arquivos a partir da raiz deste repositório:

```bash
python curso-python/aula1.py
```
